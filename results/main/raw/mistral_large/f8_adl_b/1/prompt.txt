# Task f8_adl_b: Bankruptcy Procedure (Insurance Draw and Loss Sharing)

## 1. Goal
Implement the bankruptcy procedure:
```python
def handle_bankruptcy(engine: Any, account_id: str, pre_position: int) -> list[Report]:
```
in `exchange_core/handlers/bankruptcy.py`.

A liquidation can leave an account with negative cash. The procedure covers that deficit first from the fee vault and then by sharing the rest among the accounts on the other side of the liquidated position. It changes the state in place and returns its reports.

The public tests for this task are shown in full in the "Public Tests (Visible)" section of the prompt.

## 2. Interface

```python
from exchange_core.types import Report

def handle_bankruptcy(engine: "Engine", account_id: str, pre_position: int) -> list[Report]:
    """Cover the deficit of a just-liquidated account and return the reports in order."""
```

### How the procedure is called (this part already exists, you do not write it)

A `PRICE_CRASH` event carries a `mark_price`. The engine handles it exactly like a `PRICE_SHOCK` event (the margin waterfall: it sets the mark price, examines the accounts except `LIQ` in ascending account-id order, cancels resting orders of an account in breach and, if it is still in breach, liquidates its whole position against `LIQ` at the mark price). The only difference: right after each `LIQUIDATED` report, the engine calls `handle_bankruptcy(engine, account_id, pre_position)` for the liquidated account and appends the returned reports directly after that `LIQUIDATED` report, before it examines the next account. `pre_position` is the signed position of the account before the liquidation (the `qty` of the `LIQUIDATED` report). The engine reads the live state, so the cash that your procedure takes from an account counts when that account is examined later in the same event. An account that was already examined is not examined again. `PRICE_SHOCK` never calls the procedure.

When your procedure is called, the liquidated account has `position == 0` and no resting order. The procedure does not examine, cancel or liquidate any account: it only does what the rules below say.

### The `engine` argument

`engine` is the exchange `Engine` object. The procedure may use this member:

- `engine.state`: the `EngineState` instance, described in the `exchange_core/state.py` context file below. The procedure reads it and changes it in place. `engine.state.accounts` maps each account id to an `Account` (`free_cash`, `locked_margin`, `position`, `volume`). `engine.state.fee_vault` is the fee vault.

The `Engine` class itself is not part of this task. Use only the member listed here; no other attribute of `engine` is available.

## 3. Rules

**R-L1.** The deficit of the liquidated account X is `max(0, -free_cash)` of X at the moment the procedure is called. If the deficit is 0, nothing changes and the procedure returns no report.

**R-L2.** The fee vault pays first. `cover = min(deficit, max(0, fee_vault))`. If `cover > 0`: `fee_vault` decreases by `cover`, `free_cash` of X increases by `cover`, and the procedure reports `Report(kind="INSURANCE_DRAWN", account=X, qty=cover)`. The rest is `remaining = deficit - cover`. If `remaining == 0`, the procedure ends.

**R-L3.** The rest is shared by the accounts on the other side of the liquidated position. An account is **eligible** when it is neither `LIQ` nor X, its position is not 0, and its position has the opposite sign to `pre_position`. The weight of an eligible account is `abs(position)`. Let `total` be the sum of all weights. Each eligible account first gets `base = remaining * weight // total` (floor division). The units that remain, `leftover = remaining - sum(base)`, are always fewer than the number of eligible accounts. Sort the eligible accounts by descending weight; accounts with the same weight are sorted by ascending account id (string order: `"A10"` comes before `"A2"`). Each of the first `leftover` accounts in this order gets one more unit. The result is the `share` of each eligible account.
- Each eligible account pays its `share` from `free_cash`. The cash can become negative; nothing else is done for that account (no cancel, no liquidation, no check).
- `free_cash` of X increases by `remaining`.
- For each eligible account with `share > 0`, in ascending account-id order (string order), the procedure reports `Report(kind="ADL_APPLIED", account=<that account>, qty=share)`.

**R-L4.** If `remaining > 0` and no account is eligible, nothing else changes: X keeps its negative cash and the procedure reports `Report(kind="BAD_DEBT", account=X, qty=remaining)`.

**R-L5.** The reports of the procedure are, in this order: `INSURANCE_DRAWN` (if any), then all the `ADL_APPLIED` reports, or `BAD_DEBT`; never both. Total cash plus `fee_vault` is unchanged by the procedure. Positions, locks and volumes do not change.

```python
"""tasks/f8_adl_b/public_tests/test_f8_adl_b.py
Public unit tests for task f8_adl_b.
"""
from exchange_core.config import EngineConfig
from exchange_core.engine import Engine
from exchange_core.handlers.bankruptcy import handle_bankruptcy
from exchange_core.types import Event

P = 100_000_000
IDS = ["A1", "A2", "A3", "A10", "A11", "LIQ"]


def make(cash: dict, positions: dict, vault: int = 0) -> Engine:
    """An engine whose accounts are set directly (no trading)."""
    eng = Engine(EngineConfig(), {a: 0 for a in IDS}, mark_price=P)
    for acc, value in cash.items():
        eng.state.accounts[acc].free_cash = value
    for acc, value in positions.items():
        eng.state.accounts[acc].position = value
    eng.state.fee_vault = vault
    return eng


def view(eng):
    return {a: (v.free_cash, v.position) for a, v in eng.state.accounts.items()}


def test_no_deficit_changes_nothing():
    eng = make({"A1": 5_000}, {})
    before = view(eng)
    assert handle_bankruptcy(eng, "A1", 3) == []
    assert view(eng) == before and eng.state.fee_vault == 0


def test_vault_covers_the_whole_deficit():
    eng = make({"A1": -50}, {}, vault=80)
    reps = handle_bankruptcy(eng, "A1", 3)
    assert [(r.kind, r.account, r.qty) for r in reps] == [("INSURANCE_DRAWN", "A1", 50)]
    assert eng.state.accounts["A1"].free_cash == 0 and eng.state.fee_vault == 30


def test_vault_first_then_loss_is_shared_pro_rata():
    # A1 was long (pre_position 5). Eligible: the shorts A2 (weight 1) and A3 (weight 3).
    eng = make({"A1": -110, "A2": 1_000, "A3": 1_000}, {"A2": -1, "A3": -3}, vault=30)
    reps = handle_bankruptcy(eng, "A1", 5)
    assert [(r.kind, r.account, r.qty) for r in reps] == [
        ("INSURANCE_DRAWN", "A1", 30), ("ADL_APPLIED", "A2", 20), ("ADL_APPLIED", "A3", 60),
    ]
    cash = {a: v.free_cash for a, v in eng.state.accounts.items()}
    assert cash["A1"] == 0 and cash["A2"] == 980 and cash["A3"] == 940
    assert eng.state.fee_vault == 0


def test_only_the_other_side_pays_and_liq_never_pays():
    # A3 was short (pre_position -2). Eligible: the longs. A1 is short too and LIQ is long.
    eng = make(
        {"A3": -90, "A1": 500, "A2": 500, "LIQ": 500}, {"A1": -4, "A2": 6, "LIQ": 9}
    )
    reps = handle_bankruptcy(eng, "A3", -2)
    assert [(r.kind, r.account, r.qty) for r in reps] == [("ADL_APPLIED", "A2", 90)]
    assert eng.state.accounts["A1"].free_cash == 500
    assert eng.state.accounts["LIQ"].free_cash == 500


def test_bad_debt_when_nobody_can_share():
    eng = make({"A1": -40, "LIQ": 500}, {"LIQ": -3})
    reps = handle_bankruptcy(eng, "A1", 3)
    assert [(r.kind, r.account, r.qty) for r in reps] == [("BAD_DEBT", "A1", 40)]
    assert eng.state.accounts["A1"].free_cash == -40


def test_price_crash_runs_it_and_price_shock_does_not():
    def crash_engine():
        # A1 holds 5 long with negative cash (it bought on credit); A2 is the 5 short.
        return make({"A1": -400_000_000, "A2": 2_000_000_000}, {"A1": 5, "A2": -5},
                    vault=100_000_000)

    eng = crash_engine()
    reps = eng.process(Event(kind="PRICE_CRASH", mark_price=20_000_000))
    assert [(r.kind, r.account, r.qty) for r in reps] == [
        ("MARK_SET", "", 0),
        ("LIQUIDATED", "A1", 5),
        ("INSURANCE_DRAWN", "A1", 100_000_000),
        ("ADL_APPLIED", "A2", 200_000_000),
    ]
    assert eng.state.accounts["A1"].free_cash == 0

    eng = crash_engine()
    reps = eng.process(Event(kind="PRICE_SHOCK", mark_price=20_000_000))
    assert [r.kind for r in reps] == ["MARK_SET", "LIQUIDATED"]
    assert eng.state.accounts["A1"].free_cash == -300_000_000
```

```python
"""exchange_core/state.py

See docs/05_INVARIANTS_AND_DATA.md.

from dataclasses import dataclass, field

from exchange_core.types import FixMsg, Order


@dataclass
class Account:
    """An account on the exchange.
    Tracks cash balance, locked margin, position, and cumulative volume.
    """
    free_cash: int
    locked_margin: int
    position: int
    volume: int

    def clone(self) -> "Account":
        return Account(
            free_cash=self.free_cash,
            locked_margin=self.locked_margin,
            position=self.position,
            volume=self.volume,
        )


@dataclass
class SessionState:
    """FIX session state.
    Tracks current epoch, expected next sequence number, and out-of-order buffer.
    """
    epoch: int
    next_seq: int
    buffer: dict[int, FixMsg] = field(default_factory=dict)

    def clone(self) -> "SessionState":
        return SessionState(
            epoch=self.epoch,
            next_seq=self.next_seq,
            buffer=dict(self.buffer),
        )


@dataclass
class EngineState:
    """Single container for all mutable engine state.

    Rule ENG-07: The engine must keep all state in one EngineState object.
    Rule ENG-08: EngineState must support snapshot() and restore().
    A restore must give a state with the same hash as the snapshot.
    """
    accounts: dict[str, Account]
    orders: dict[int, Order]  # resting orders by order_id
    fee_vault: int
    next_order_id: int
    next_prio_seq: int
    margin_bps: int
    mark_price: int
    sessions: dict[str, SessionState]
    initial_total: int

    def snapshot(self) -> "EngineState":
        """Produce an independent deep snapshot of the engine state."""
        return EngineState(
            accounts={k: v.clone() for k, v in self.accounts.items()},
            orders={k: Order(**v.__dict__) for k, v in self.orders.items()},
            fee_vault=self.fee_vault,
            next_order_id=self.next_order_id,
            next_prio_seq=self.next_prio_seq,
            margin_bps=self.margin_bps,
            mark_price=self.mark_price,
            sessions={k: v.clone() for k, v in self.sessions.items()},
            initial_total=self.initial_total,
        )

    def restore(self, snap: "EngineState") -> None:
        """Restore all state in-place from an earlier snapshot (Rule R-A4, ENG-08)."""
        self.accounts = {k: v.clone() for k, v in snap.accounts.items()}
        self.orders = {k: Order(**v.__dict__) for k, v in snap.orders.items()}
        self.fee_vault = snap.fee_vault
        self.next_order_id = snap.next_order_id
        self.next_prio_seq = snap.next_prio_seq
        self.margin_bps = snap.margin_bps
        self.mark_price = snap.mark_price
        self.sessions = {k: v.clone() for k, v in snap.sessions.items()}
        self.initial_total = snap.initial_total
```

```python
"""exchange_core/intmath.py
Integer arithmetic helpers.

Rule R-U1: All amounts, prices, and quantities are integers.
No other module does rounding.
No float is used. No bare / operator is used.
"""


def round_half_even(n: int, d: int) -> int:
    """Divide n by d and round to the nearest integer.

    Rule R-U2: When the result is exactly halfway, round to the even integer.

    Algorithm:
      Let q, r = divmod(n, d).
      If 2*r > d:  return q + 1.
      If 2*r == d: return q + (q % 2).   # q is odd -> +1, q is even -> +0
      Otherwise:   return q.

    Preconditions: n >= 0, d > 0.
    """
    q, r = divmod(n, d)
    if 2 * r > d:
        return q + 1
    if 2 * r == d:
        return q + (q % 2)
    return q


def ceil_div(n: int, d: int) -> int:
    """Return the smallest integer that is not below n / d.

    Rule R-U3: Equals -((-n) // d).

    Preconditions: n >= 0, d > 0.
    """
    return -((-n) // d)
```

```python
"""exchange_core/book.py
Book primitives. Derived views of resting orders in EngineState.
No rule logic belongs here (docs/03_ARCHITECTURE.md).

from typing import Optional

from exchange_core.state import EngineState
from exchange_core.types import Order


def add_order(state: EngineState, order: Order) -> None:
    """Add a resting order to the state."""
    state.orders[order.order_id] = order


def remove_order(state: EngineState, order_id: int) -> Optional[Order]:
    """Remove and return a resting order by order_id."""
    return state.orders.pop(order_id, None)


def get_order(state: EngineState, order_id: int) -> Optional[Order]:
    """Retrieve a resting order by order_id."""
    return state.orders.get(order_id)


def get_bids(state: EngineState) -> list[Order]:
    """Return all resting BUY orders in priority order (Rule R-B2)."""
    bids = [o for o in state.orders.values() if o.side == "BUY" and o.leaves > 0]
    bids.sort(key=lambda o: (-o.price, o.prio_seq))
    return bids


def get_asks(state: EngineState) -> list[Order]:
    """Return all resting SELL orders in priority order (Rule R-B2)."""
    asks = [o for o in state.orders.values() if o.side == "SELL" and o.leaves > 0]
    asks.sort(key=lambda o: (o.price, o.prio_seq))
    return asks


def best_bid(state: EngineState) -> Optional[int]:
    """Return highest bid price, or None if no bids exist."""
    bids = get_bids(state)
    return bids[0].price if bids else None


def best_ask(state: EngineState) -> Optional[int]:
    """Return lowest ask price, or None if no asks exist."""
    asks = get_asks(state)
    return asks[0].price if asks else None


def get_account_orders(state: EngineState, account: str) -> list[Order]:
    """Return all resting orders for an account, sorted by prio_seq ascending (Rule R-W3)."""
    orders = [o for o in state.orders.values() if o.account == account and o.leaves > 0]
    orders.sort(key=lambda o: o.prio_seq)
    return orders
```

```python
"""exchange_core/ledger.py
Cash and lock primitives.
No rule logic belongs here (docs/03_ARCHITECTURE.md).
"""
from typing import Optional

from exchange_core.state import Account, EngineState


def get_account(state: EngineState, account_id: str) -> Optional[Account]:
    """Retrieve an account by ID."""
    return state.accounts.get(account_id)


def has_account(state: EngineState, account_id: str) -> bool:
    """Return True if the account exists."""
    return account_id in state.accounts


def lock_cash(state: EngineState, account_id: str, amount: int) -> None:
    """Move amount from free_cash to locked_margin."""
    acc = state.accounts[account_id]
    acc.free_cash -= amount
    acc.locked_margin += amount


def release_lock(state: EngineState, account_id: str, amount: int) -> None:
    """Move amount from locked_margin to free_cash."""
    acc = state.accounts[account_id]
    acc.locked_margin -= amount
    acc.free_cash += amount


def transfer_cash(state: EngineState, from_id: str, to_id: str, amount: int) -> None:
    """Transfer free_cash from one account to another."""
    state.accounts[from_id].free_cash -= amount
    state.accounts[to_id].free_cash += amount


def adjust_position(state: EngineState, account_id: str, delta: int) -> None:
    """Adjust position by delta (positive = increase, negative = decrease)."""
    state.accounts[account_id].position += delta


def pay_fee(state: EngineState, account_id: str, fee: int) -> None:
    """Deduct fee from account free_cash and deposit to fee_vault."""
    state.accounts[account_id].free_cash -= fee
    state.fee_vault += fee


def pay_rebate(state: EngineState, account_id: str, rebate: int) -> None:
    """Credit rebate from fee_vault to account free_cash."""
    state.fee_vault -= rebate
    state.accounts[account_id].free_cash += rebate


def add_volume(state: EngineState, account_id: str, notional: int) -> None:
    """Add notional to an account's trading volume."""
    state.accounts[account_id].volume += notional
```
