# Task f7_funding_b: Funding Payments Handler

## 1. Goal
Implement the FUNDING handler:
```python
def handle_funding(engine: Any, event: Event) -> list[Report]:
```
in `exchange_core/handlers/funding.py`.

A FUNDING event moves cash between accounts that hold long positions and accounts that hold short positions, books the net rounding difference in the fee vault, and then runs the margin waterfall.

The public tests for this task are shown in full in the "Public Tests (Visible)" section of the prompt.

## 2. Interface

```python
from exchange_core.types import Event, Report

def handle_funding(engine: "Engine", event: Event) -> list[Report]:
    """Apply funding payments and return the reports in order."""
```

For a FUNDING event, `event.bps` holds the funding rate in **parts per million** (it can be negative). The other event fields are not used.

### The `engine` argument

`engine` is the exchange `Engine` object. The handler may use these members:

- `engine.state`: the `EngineState` instance, described in the `exchange_core/state.py` context file below. The handler reads it and changes it in place. The current mark price is `engine.state.mark_price`.
- `engine.cfg`: the `EngineConfig` instance. `engine.cfg.ppm` is the divisor for parts per million (1,000,000).
- `engine.dispatch(event: Event) -> list[Report]`: runs the event through the engine's own handler for `event.kind` and returns its reports. `engine.process(event)` does exactly the same.

The `Engine` class itself is not part of this task. Use only the members listed here; no other attribute of `engine` is available. `round_half_even` is in `exchange_core/intmath.py`; its documented precondition is `n >= 0`.

## 3. Rules

**R-Y1.** The engine clamps the rate to the range -3000 to +3000, both limits included. The clamped value is `rate`.

**R-Y2.** If `rate != 0`, the engine processes every account with `position != 0`, in ascending account-id order (the `LIQ` account is included). For each such account:
- `notional = abs(position) * mark_price`
- `amount = round_half_even(notional * abs(rate), ppm)`. The rounding is applied to this non-negative value.
- The account **pays** `amount` when it is long and `rate > 0`, or short and `rate < 0`. In every other case it **receives** `amount`.
- A payment is subtracted from `free_cash`. A receipt is added to `free_cash`. `free_cash` can become negative.

Locks, volume and positions do not change.

**R-Y3.** The rounding is done per account, so the payments and receipts need not cancel. The engine adds the net of all payments (payments minus receipts; the net can be negative) to `state.fee_vault`. Total cash plus `fee_vault` is therefore unchanged.

**R-Y4.** The first report is `Report(kind="FUNDING_APPLIED", bps=rate, qty=n)`, where `rate` is the clamped rate and `n` is the number of accounts processed in R-Y2. If `rate == 0`, R-Y2 processes no account, so `n = 0` (even if some accounts hold positions). If `rate != 0`, `n` counts every account with `position != 0`, including an account whose `amount` rounds to 0.

**R-Y5.** After the payments, the engine always runs the margin waterfall at the current mark price: it dispatches `Event(kind="PRICE_SHOCK", mark_price=state.mark_price)` through `engine.dispatch` and appends the returned reports, in their own order, after `FUNDING_APPLIED`. This also happens when `rate == 0`.

"""tasks/f7_funding_b/public_tests/test_f7_funding_b.py
Public unit tests for task f7_funding_b.
"""
from exchange_core.config import EngineConfig
from exchange_core.engine import Engine
from exchange_core.types import Event

P = 100_000_000


def make():
    accounts = {"A1": 5_000_000_000, "A2": 5_000_000_000, "LIQ": 50_000_000_000}
    return Engine(EngineConfig(), accounts, mark_price=P)


def trade(eng, qty):
    """A1 sells qty to A2 at P: A1 is short, A2 is long."""
    eng.process(Event(kind="NEW_LIMIT", account="A1", side="SELL", price=P, qty=qty))
    eng.process(Event(kind="NEW_LIMIT", account="A2", side="BUY", price=P, qty=qty))


def cash(eng):
    return {a: v.free_cash for a, v in eng.state.accounts.items()}


def test_no_positions_only_reports():
    eng = make()
    reps = eng.process(Event(kind="FUNDING", bps=1000))
    assert [r.kind for r in reps] == ["FUNDING_APPLIED", "MARK_SET"]
    assert reps[0].bps == 1000 and reps[0].qty == 0
    assert reps[1].mark_price == P


def test_positive_rate_long_pays_short():
    eng = make()
    trade(eng, 3)
    before, vault = cash(eng), eng.state.fee_vault
    reps = eng.process(Event(kind="FUNDING", bps=1000))
    amount = 3 * P * 1000 // 1_000_000
    after = cash(eng)
    assert after["A2"] == before["A2"] - amount
    assert after["A1"] == before["A1"] + amount
    assert after["LIQ"] == before["LIQ"]
    assert eng.state.fee_vault == vault
    assert reps[0].kind == "FUNDING_APPLIED" and reps[0].qty == 2


def test_negative_rate_short_pays_long():
    eng = make()
    trade(eng, 2)
    before = cash(eng)
    eng.process(Event(kind="FUNDING", bps=-500))
    amount = 2 * P * 500 // 1_000_000
    after = cash(eng)
    assert after["A1"] == before["A1"] - amount
    assert after["A2"] == before["A2"] + amount


def test_rate_is_clamped():
    eng = make()
    trade(eng, 1)
    before = cash(eng)
    reps = eng.process(Event(kind="FUNDING", bps=9000))
    assert reps[0].bps == 3000
    assert before["A2"] - cash(eng)["A2"] == P * 3000 // 1_000_000
```

"""exchange_core/state.py
Mutable state classes for the exchange engine.
See docs/05_INVARIANTS_AND_DATA.md.
"""
from dataclasses import dataclass, field

from exchange_core.types import FixMsg, Order


@dataclass
class Account:
    """An account on the exchange.
    Tracks cash balance, locked margin, position, and cumulative volume.
    """
    free_cash: int
    locked_margin: int
    position: int
    volume: int

    def clone(self) -> "Account":
        return Account(
            free_cash=self.free_cash,
            locked_margin=self.locked_margin,
            position=self.position,
            volume=self.volume,
        )


@dataclass
class SessionState:
    """FIX session state.
    Tracks current epoch, expected next sequence number, and out-of-order buffer.
    """
    epoch: int
    next_seq: int
    buffer: dict[int, FixMsg] = field(default_factory=dict)

    def clone(self) -> "SessionState":
        return SessionState(
            epoch=self.epoch,
            next_seq=self.next_seq,
            buffer=dict(self.buffer),
        )


@dataclass
class EngineState:
    """Single container for all mutable engine state.

    Rule ENG-07: The engine must keep all state in one EngineState object.
    Rule ENG-08: EngineState must support snapshot() and restore().
    A restore must give a state with the same hash as the snapshot.
    """
    accounts: dict[str, Account]
    orders: dict[int, Order]  # resting orders by order_id
    fee_vault: int
    next_order_id: int
    next_prio_seq: int
    margin_bps: int
    mark_price: int
    sessions: dict[str, SessionState]
    initial_total: int

    def snapshot(self) -> "EngineState":
        """Produce an independent deep snapshot of the engine state."""
        return EngineState(
            accounts={k: v.clone() for k, v in self.accounts.items()},
            orders={k: Order(**v.__dict__) for k, v in self.orders.items()},
            fee_vault=self.fee_vault,
            next_order_id=self.next_order_id,
            next_prio_seq=self.next_prio_seq,
            margin_bps=self.margin_bps,
            mark_price=self.mark_price,
            sessions={k: v.clone() for k, v in self.sessions.items()},
            initial_total=self.initial_total,
        )

    def restore(self, snap: "EngineState") -> None:
        """Restore all state in-place from an earlier snapshot (Rule R-A4, ENG-08)."""
        self.accounts = {k: v.clone() for k, v in snap.accounts.items()}
        self.orders = {k: Order(**v.__dict__) for k, v in snap.orders.items()}
        self.fee_vault = snap.fee_vault
        self.next_order_id = snap.next_order_id
        self.next_prio_seq = snap.next_prio_seq
        self.margin_bps = snap.margin_bps
        self.mark_price = snap.mark_price
        self.sessions = {k: v.clone() for k, v in snap.sessions.items()}
        self.initial_total = snap.initial_total

"""exchange_core/intmath.py
Integer arithmetic helpers.

Rule R-U1: All amounts, prices, and quantities are integers.
No other module does rounding.
No float is used. No bare / operator is used.
"""


def round_half_even(n: int, d: int) -> int:
    """Divide n by d and round to the nearest integer.

    Rule R-U2: When the result is exactly halfway, round to the even integer.

    Algorithm:
      Let q, r = divmod(n, d).
      If 2*r > d:  return q + 1.
      If 2*r == d: return q + (q % 2).   # q is odd -> +1, q is even -> +0
      Otherwise:   return q.

    Preconditions: n >= 0, d > 0.
    """
    q, r = divmod(n, d)
    if 2 * r > d:
        return q + 1
    if 2 * r == d:
        return q + (q % 2)
    return q


def ceil_div(n: int, d: int) -> int:
    """Return the smallest integer that is not below n / d.

    Rule R-U3: Equals -((-n) // d).

    Preconditions: n >= 0, d > 0.
    """
    return -((-n) // d)
```

"""exchange_core/book.py
Book primitives. Derived views of resting orders in EngineState.
No rule logic belongs here (docs/03_ARCHITECTURE.md).

from typing import Optional

from exchange_core.state import EngineState
from exchange_core.types import Order


def add_order(state: EngineState, order: Order) -> None:
    """Add a resting order to the state."""
    state.orders[order.order_id] = order


def remove_order(state: EngineState, order_id: int) -> Optional[Order]:
    """Remove and return a resting order by order_id."""
    return state.orders.pop(order_id, None)


def get_order(state: EngineState, order_id: int) -> Optional[Order]:
    """Retrieve a resting order by order_id."""
    return state.orders.get(order_id)


def get_bids(state: EngineState) -> list[Order]:
    """Return all resting BUY orders in priority order (Rule R-B2)."""
    bids = [o for o in state.orders.values() if o.side == "BUY" and o.leaves > 0]
    bids.sort(key=lambda o: (-o.price, o.prio_seq))
    return bids


def get_asks(state: EngineState) -> list[Order]:
    """Return all resting SELL orders in priority order (Rule R-B2)."""
    asks = [o for o in state.orders.values() if o.side == "SELL" and o.leaves > 0]
    asks.sort(key=lambda o: (o.price, o.prio_seq))
    return asks


def best_bid(state: EngineState) -> Optional[int]:
    """Return highest bid price, or None if no bids exist."""
    bids = get_bids(state)
    return bids[0].price if bids else None


def best_ask(state: EngineState) -> Optional[int]:
    """Return lowest ask price, or None if no asks exist."""
    asks = get_asks(state)
    return asks[0].price if asks else None


def get_account_orders(state: EngineState, account: str) -> list[Order]:
    """Return all resting orders for an account, sorted by prio_seq ascending (Rule R-W3)."""
    orders = [o for o in state.orders.values() if o.account == account and o.leaves > 0]
    orders.sort(key=lambda o: o.prio_seq)
    return orders

"""exchange_core/ledger.py
Cash and lock primitives.
No rule logic belongs here (docs/03_ARCHITECTURE.md).
"""
from typing import Optional

from exchange_core.state import Account, EngineState


def get_account(state: EngineState, account_id: str) -> Optional[Account]:
    """Retrieve an account by ID."""
    return state.accounts.get(account_id)


def has_account(state: EngineState, account_id: str) -> bool:
    """Return True if the account exists."""
    return account_id in state.accounts


def lock_cash(state: EngineState, account_id: str, amount: int) -> None:
    """Move amount from free_cash to locked_margin."""
    acc = state.accounts[account_id]
    acc.free_cash -= amount
    acc.locked_margin += amount


def release_lock(state: EngineState, account_id: str, amount: int) -> None:
    """Move amount from locked_margin to free_cash."""
    acc = state.accounts[account_id]
    acc.locked_margin -= amount
    acc.free_cash += amount


def transfer_cash(state: EngineState, from_id: str, to_id: str, amount: int) -> None:
    """Transfer free_cash from one account to another."""
    state.accounts[from_id].free_cash -= amount
    state.accounts[to_id].free_cash += amount


def adjust_position(state: EngineState, account_id: str, delta: int) -> None:
    """Adjust position by delta (positive = increase, negative = decrease)."""
    state.accounts[account_id].position += delta


def pay_fee(state: EngineState, account_id: str, fee: int) -> None:
    """Deduct fee from account free_cash and deposit to fee_vault."""
    state.accounts[account_id].free_cash -= fee
    state.fee_vault += fee


def pay_rebate(state: EngineState, account_id: str, rebate: int) -> None:
    """Credit rebate from fee_vault to account free_cash."""
    state.fee_vault -= rebate
    state.accounts[account_id].free_cash += rebate


def add_volume(state: EngineState, account_id: str, notional: int) -> None:
    """Add notional to an account's trading volume."""
    state.accounts[account_id].volume += notional
