# Task f6_match_b: Order Entry and Matching Handler

## 1. Goal
Implement the NEW_LIMIT handler:
```python
def handle_new_limit(engine: Any, event: Event) -> list[Report]:
```
in `exchange_core/handlers/new_limit.py`.

The handler validates an incoming limit order, reserves margin, matches it against the resting book, settles every fill, and either cancels or rests the remainder. Fee settlement is not part of this task: call `settle_fill` for every fill.

The public tests for this task are shown in full in the "Public Tests (Visible)" section of the prompt.

## 2. Interface

```python
from exchange_core.types import Event, Report

def handle_new_limit(engine: "Engine", event: Event) -> list[Report]:
    """Process a NEW_LIMIT event and return the reports in order."""
```

`event` has `account`, `side` (`"BUY"` or `"SELL"`), `price`, `qty` and `flag` (`"NONE"`, `"IOC"` or `"POST_ONLY"`).

### The `engine` argument

`engine` is the exchange `Engine` object. The handler may use these members:

- `engine.state`: the `EngineState` instance, described in the `exchange_core/state.py` context file below. The handler reads it and changes it in place.
- `engine.cfg`: the `EngineConfig` instance (`engine.cfg.tick` is the tick size).
- `settle_fill(engine, fill)`: imported with `from exchange_core.handlers.settle import settle_fill`. It takes a `Fill` (see `exchange_core/types.py`) and performs R-M4 steps 1, 2, 5 and 6: it moves the cash and the positions, settles fees, rebates and volume, and returns `[Report.fill(...)]`. It does not touch `cum_qty`, locks or the book, and it reads nothing from them: it only reads and changes `accounts` and `fee_vault`. It does not matter whether the handler calls it before or after R-M4 steps 3 and 4.

The `Engine` class itself is not part of this task. Use only the members listed here; no other attribute of `engine` is available.

A resting order is stored in `engine.state.orders[order_id]`. The helpers in `exchange_core/book.py` (`get_asks`, `get_bids`, `best_ask`, `best_bid`, `add_order`, `remove_order`) return the resting orders in priority order. `ceil_div` is in `exchange_core/intmath.py`.

## 3. Rules

**R-B3.** `prio_seq` and `order_id` come from two counters in the state (`state.next_prio_seq`, `state.next_order_id`). Both counters start at 1. The engine does not use time.

**R-B4.** The validation order for a NEW_LIMIT event is:
1. If the account does not exist, return `[Report.rejected("UNKNOWN_ACCOUNT")]`.
2. If `qty <= 0`, or `price <= 0`, or `price % tick != 0`, return `[Report.rejected("INVALID_ORDER")]`.
3. If the flag is `POST_ONLY` and the order would match now, return `[Report.rejected("POST_ONLY_WOULD_CROSS")]`. "Would match now" means that the best price on the opposite side of the book crosses the limit price (a BUY crosses when the best ask is at or below its price; a SELL crosses when the best bid is at or above its price). All resting orders count, including orders of the same account.
4. Compute `lock = ceil_div(qty * price * state.margin_bps, 10000)`. If `free_cash < lock`, return `[Report.rejected("INSUFFICIENT_MARGIN")]`.

A rejected order changes no state. A rejected order does not use a counter value.

**R-B5.** When the order is valid, the handler does these steps in order:
1. Assign `order_id` and `prio_seq` from the counters. Add 1 to each counter.
2. Create the order with `cum_qty = 0`, the event's `flag` stored in it as `flag`, and the current `state.margin_bps` stored in it as `margin_bps`.
3. Subtract `lock` from `free_cash`. Add `lock` to `locked_margin`. Store `lock` in the order.
4. Report `ACCEPTED(order_id)`.
5. Match the order (rules R-M1 to R-M4).
6. If the flag is `IOC` and `leaves > 0`, cancel the remainder with `Report.cancelled(order_id, "IOC_REMAINDER")`. Release the lock of the order: move it from `locked_margin` to `free_cash`. The order is not stored in `state.orders`.
7. If the flag is not `IOC` and `leaves > 0`, add the order to the book as a resting order (it is stored in `state.orders`).

An order that is completely filled is never stored in `state.orders`.

**R-M1.** A BUY order matches SELL resting orders with `price <= limit`. A SELL order matches BUY resting orders with `price >= limit`. The handler matches the best price first. At the same price, it matches the lowest `prio_seq` first. Matching stops when the order has `leaves == 0`, when the book has no resting order on the opposite side, or when the best opposite resting order does not cross the limit price.

**R-M2.** The fill price is the price of the resting order. The fill quantity is the smaller `leaves` of the two orders.

**R-M3.** Self-trade prevention. When the best resting order that crosses the limit price has the same account as the incoming order, the handler cancels that resting order with reason `STP`. It removes it from the book. It moves the full lock of the resting order from `locked_margin` to `free_cash`. It reports `Report.cancelled(order_id, "STP")`. It then continues to match with the next resting order. No fill occurs for the cancelled order.

**R-M4.** Effect of a fill with quantity `q` and price `p`:
1. The buyer pays `q * p` and its position changes. (Done by `settle_fill`.)
2. The seller receives `q * p`. (Done by `settle_fill`.)
3. For each of the two orders, add `q` to `cum_qty`.
4. For each of the two orders, compute `new_lock = ceil_div(leaves * order.price * order.margin_bps, 10000)`, using the `margin_bps` stored in that order. Move `old_lock - new_lock` from `locked_margin` to `free_cash`. Store `new_lock` in the order.
5. Settle the fees. (Done by `settle_fill`.)
6. Report the fill. (Done by `settle_fill`; the handler adds the returned reports to its own list.)

A fill can make `free_cash` negative. This is allowed. A resting order with `leaves == 0` leaves the book.

**R-M5.** When a fill makes `leaves == 0` for an order (including the incoming order), its `new_lock` is 0, so the whole old lock moves from `locked_margin` to `free_cash`.

The handler builds the `Fill` for `settle_fill` with `buy_order_id` and `sell_order_id` of the two orders, the fill `price` and `qty`, `taker_order_id` equal to the incoming order, and `buyer` and `seller` equal to the accounts of the buy order and the sell order.

## 4. Report order
The reports are returned in the order in which the events happen: `ACCEPTED`, then for each step of matching the `STP` cancellation or the `FILL`, then `IOC_REMAINDER` if it applies.

```python
"""tasks/f6_match_b/public_tests/test_f6_match_b.py
Public unit tests for task f6_match_b.

from exchange_core.config import EngineConfig
from exchange_core.engine import Engine
from exchange_core.types import Event, Report

P = 100_000_000


def make(accounts=None):
    accounts = accounts or {"A1": 2_000_000_000, "A2": 2_000_000_000, "LIQ": 10_000_000_000}
    return Engine(EngineConfig(), accounts, mark_price=P)


def new(eng, acc, side, price, qty, flag="NONE"):
    return eng.process(
        Event(kind="NEW_LIMIT", account=acc, side=side, price=price, qty=qty, flag=flag)
    )


def test_resting_order_locks_margin():
    eng = make()
    reps = new(eng, "A1", "BUY", P, 3)
    assert reps == [Report.accepted(1)]
    acc = eng.state.accounts["A1"]
    assert acc.locked_margin == 3 * P * 2000 // 10000
    assert acc.free_cash == 2_000_000_000 - acc.locked_margin
    assert 1 in eng.state.orders and eng.state.next_order_id == 2


def test_validation_rejects_change_nothing():
    eng = make()
    h = eng.state_hash()
    assert new(eng, "NOPE", "BUY", P, 1) == [Report.rejected("UNKNOWN_ACCOUNT")]
    assert new(eng, "A1", "BUY", P + 5, 1) == [Report.rejected("INVALID_ORDER")]
    assert new(eng, "A1", "BUY", P, 0) == [Report.rejected("INVALID_ORDER")]
    assert eng.state_hash() == h


def test_insufficient_margin_is_rejected():
    eng = make({"A1": 10_000_000, "A2": 1_000_000_000, "LIQ": 10_000_000_000})
    assert new(eng, "A1", "BUY", P, 1) == [Report.rejected("INSUFFICIENT_MARGIN")]
    assert eng.state.next_order_id == 1


def test_full_cross_fills_at_resting_price():
    eng = make()
    new(eng, "A2", "SELL", P, 2)
    reps = new(eng, "A1", "BUY", P + 10_000, 2)
    assert reps[0] == Report.accepted(2)
    assert reps[1] == Report.fill(2, 1, P, 2, 2)
    assert len(reps) == 2
    assert eng.state.accounts["A1"].position == 2
    assert eng.state.accounts["A2"].position == -2
    assert eng.state.accounts["A1"].locked_margin == 0
    assert eng.state.accounts["A2"].locked_margin == 0
    assert eng.state.orders == {}


def test_partial_fill_rests_remainder():
    eng = make()
    new(eng, "A2", "SELL", P, 2)
    reps = new(eng, "A1", "BUY", P, 5)
    assert reps == [Report.accepted(2), Report.fill(2, 1, P, 2, 2)]
    rest = eng.state.orders[2]
    assert rest.cum_qty == 2 and rest.leaves == 3
    assert rest.lock == 3 * P * 2000 // 10000
    assert eng.state.accounts["A1"].locked_margin == rest.lock


def test_ioc_remainder_is_cancelled_and_not_stored():
    eng = make()
    new(eng, "A2", "SELL", P, 1)
    reps = new(eng, "A1", "BUY", P, 4, flag="IOC")
    assert reps == [
        Report.accepted(2),
        Report.fill(2, 1, P, 1, 2),
        Report.cancelled(2, "IOC_REMAINDER"),
    ]
    assert eng.state.orders == {}
    assert eng.state.accounts["A1"].locked_margin == 0


def test_post_only_that_would_cross_is_rejected():
    eng = make()
    new(eng, "A2", "SELL", P, 2)
    h = eng.state_hash()
    assert new(eng, "A1", "BUY", P, 1, flag="POST_ONLY") == [
        Report.rejected("POST_ONLY_WOULD_CROSS")
    ]
    assert eng.state_hash() == h


def test_self_trade_cancels_resting_order():
    eng = make()
    new(eng, "A1", "SELL", P, 2)
    reps = new(eng, "A1", "BUY", P, 1)
    assert reps == [Report.accepted(2), Report.cancelled(1, "STP")]
    assert 1 not in eng.state.orders and 2 in eng.state.orders
    assert eng.state.accounts["A1"].locked_margin == P * 2000 // 10000
```

```python
"""exchange_core/state.py
Mutable state classes for the exchange engine.
See docs/05_INVARIANTS_AND_DATA.md.

from dataclasses import dataclass, field

from exchange_core.types import FixMsg, Order


@dataclass
class Account:
    """An account on the exchange.
    Tracks cash balance, locked margin, position, and cumulative volume.
    """
    free_cash: int
    locked_margin: int
    position: int
    volume: int

    def clone(self) -> "Account":
        return Account(
            free_cash=self.free_cash,
            locked_margin=self.locked_margin,
            position=self.position,
            volume=self.volume,
        )


@dataclass
class SessionState:
    """FIX session state.
    Tracks current epoch, expected next sequence number, and out-of-order buffer.
    """
    epoch: int
    next_seq: int
    buffer: dict[int, FixMsg] = field(default_factory=dict)

    def clone(self) -> "SessionState":
        return SessionState(
            epoch=self.epoch,
            next_seq=self.next_seq,
            buffer=dict(self.buffer),
        )


@dataclass
class EngineState:
    """Single container for all mutable engine state.

    Rule ENG-07: The engine must keep all state in one EngineState object.
    Rule ENG-08: EngineState must support snapshot() and restore().
    A restore must give a state with the same hash as the snapshot.
    """
    accounts: dict[str, Account]
    orders: dict[int, Order]  # resting orders by order_id
    fee_vault: int
    next_order_id: int
    next_prio_seq: int
    margin_bps: int
    mark_price: int
    sessions: dict[str, SessionState]
    initial_total: int

    def snapshot(self) -> "EngineState":
        """Produce an independent deep snapshot of the engine state."""
        return EngineState(
            accounts={k: v.clone() for k, v in self.accounts.items()},
            orders={k: Order(**v.__dict__) for k, v in self.orders.items()},
            fee_vault=self.fee_vault,
            next_order_id=self.next_order_id,
            next_prio_seq=self.next_prio_seq,
            margin_bps=self.margin_bps,
            mark_price=self.mark_price,
            sessions={k: v.clone() for k, v in self.sessions.items()},
            initial_total=self.initial_total,
        )

    def restore(self, snap: "EngineState") -> None:
        """Restore all state in-place from an earlier snapshot (Rule R-A4, ENG-08)."""
        self.accounts = {k: v.clone() for k, v in snap.accounts.items()}
        self.orders = {k: Order(**v.__dict__) for k, v in snap.orders.items()}
        self.fee_vault = snap.fee_vault
        self.next_order_id = snap.next_order_id
        self.next_prio_seq = snap.next_prio_seq
        self.margin_bps = snap.margin_bps
        self.mark_price = snap.mark_price
        self.sessions = {k: v.clone() for k, v in snap.sessions.items()}
        self.initial_total = snap.initial_total
```

```python
"""exchange_core/intmath.py
Integer arithmetic helpers.

Rule R-U1: All amounts, prices, and quantities are integers.
No other module does rounding.
No float is used. No bare / operator is used.
"""


def round_half_even(n: int, d: int) -> int:
    """Divide n by d and round to the nearest integer.

    Rule R-U2: When the result is exactly halfway, round to the even integer.

    Algorithm:
      Let q, r = divmod(n, d).
      If 2*r > d:  return q + 1.
      If 2*r == d: return q + (q % 2).   # q is odd -> +1, q is even -> +0
      Otherwise:   return q.

    Preconditions: n >= 0, d > 0.
    """
    q, r = divmod(n, d)
    if 2 * r > d:
        return q + 1
    if 2 * r == d:
        return q + (q % 2)
    return q


def ceil_div(n: int, d: int) -> int:
    """Return the smallest integer that is not below n / d.

    Rule R-U3: Equals -((-n) // d).

    Preconditions: n >= 0, d > 0.
    """
    return -((-n) // d)
```

```python
"""exchange_core/book.py
Book primitives. Derived views of resting orders in EngineState.
No rule logic belongs here (docs/03_ARCHITECTURE.md).
"""
from typing import Optional

from exchange_core.state import EngineState
from exchange_core.types import Order


def add_order(state: EngineState, order: Order) -> None:
    """Add a resting order to the state."""
    state.orders[order.order_id] = order


def remove_order(state: EngineState, order_id: int) -> Optional[Order]:
    """Remove and return a resting order by order_id."""
    return state.orders.pop(order_id, None)


def get_order(state: EngineState, order_id: int) -> Optional[Order]:
    """Retrieve a resting order by order_id."""
    return state.orders.get(order_id)


def get_bids(state: EngineState) -> list[Order]:
    """Return all resting BUY orders in priority order (Rule R-B2)."""
    bids = [o for o in state.orders.values() if o.side == "BUY" and o.leaves > 0]
    bids.sort(key=lambda o: (-o.price, o.prio_seq))
    return bids


def get_asks(state: EngineState) -> list[Order]:
    """Return all resting SELL orders in priority order (Rule R-B2)."""
    asks = [o for o in state.orders.values() if o.side == "SELL" and o.leaves > 0]
    asks.sort(key=lambda o: (o.price, o.prio_seq))
    return asks


def best_bid(state: EngineState) -> Optional[int]:
    """Return highest bid price, or None if no bids exist."""
    bids = get_bids(state)
    return bids[0].price if bids else None


def best_ask(state: EngineState) -> Optional[int]:
    """Return lowest ask price, or None if no asks exist."""
    asks = get_asks(state)
    return asks[0].price if asks else None


def get_account_orders(state: EngineState, account: str) -> list[Order]:
    """Return all resting orders for an account, sorted by prio_seq ascending (Rule R-W3)."""
    orders = [o for o in state.orders.values() if o.account == account and o.leaves > 0]
    orders.sort(key=lambda o: o.prio_seq)
    return orders
```

```python
    """Move amount from locked_margin to free_cash."""
    acc = state.accounts[account_id]

    acc.free_cash += amount
```
