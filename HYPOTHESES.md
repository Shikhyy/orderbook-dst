# Hypotheses

The author commits these hypotheses before the first model run.
The project reports the real result, also when a prediction is wrong.

| ID | Hypothesis |
|---|---|
| H1 | For each model, the Tier 1 score is higher than the Tier 3 score. |
| H2 | For each model, variant B has a lower pass rate than variant A (paired by family). |
| H3 | When the model sees the invariant report, the pass rate increases (feedback loop). |
| H4 | A stronger model has a higher pass rate than a smaller model. |
| H5 | Most Tier 3 failures at variant B come from state that the code does not update in a second component. |
